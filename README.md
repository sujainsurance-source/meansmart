# SAFEER STUDIO — Fashion Storefront Demo

A responsive, Amazon-inspired fashion e-commerce **frontend demo** for Safeer Anna, styled with a premium forest-green, white, charcoal and subtle red palette.

## Run locally
No build tools or backend are required.

1. Clone or download this repository.
2. Open `index.html` in a modern browser.

Optional: use VS Code Live Server or another static server.

## Included
- Responsive storefront landing page and editorial sections
- Sample fashion catalogue: shirts, trousers, T-shirts and essentials
- Search, category filters, price slider and sorting
- Product quick-view modal with size selection
- Working wishlist and shopping bag with quantity controls
- Demo checkout flow (no real order or payment)
- Newsletter interaction (demo only)
- Mobile navigation and responsive layouts

## Demo limitations
- Product names, prices, ratings and inventory are sample data.
- No authentication, database, inventory sync, email service, shipping integration or payment gateway is connected.
- Checkout is intentionally a visual demo and does not process orders or payments.
- Product photography and Google Fonts load externally, so an internet connection is needed for those assets.

## Project files
- `index.html` — page structure
- `styles.css` — responsive design system
- `app.js` — catalogue and frontend interactions

## Preview
Open `index.html` locally, or enable GitHub Pages in repository Settings → Pages and select the `main` branch.
